#+TITLE: brishzgo

A Go drop-in for =zshlang/wrappers/brishz/brishzq.zsh=: it runs one zsh command
in a BrishGarden over the streaming API by default, falling back to raw and
JSON for older gardens. =brishz_stream=n= skips streaming; also set
=brishz_raw=n= to use JSON directly. It takes the same argv, environment
variables and exit statuses. What it does, how it differs from =brishzq.zsh=
and how fast it is are in [[NIGHTDIR:docs/brishzgo.md][docs/brishzgo.md]]; this readme is about building and
testing it.

Standard library only, so =go build= needs no network.

* Install
#+begin_src zsh :eval never
go-install-local "${NIGHTDIR}/golang/brishzgo"
#+end_src

That puts =brishzgo= in =~/go/bin=. It is registered in =setup/setup_go=.

[agfi:brishz] uses this binary and builds or refreshes it on demand through
[agfi:go-local-dep]. [agfi:brishz-v1] preserves the previous shell client.
Streaming passes output through while the command runs; interrupting the
client stops that command when the garden supports streaming.
Sole =-h= or =--help= shows local help. Leading =--= passes the remaining
arguments to the garden unchanged; leading =-c= remains a legacy alias.
=brishz_async=y= launches a detached worker, discarding output and returning
after local launch. Direct stdin is consumed before launch and survives the
parent's exit; the worker drains streaming replies to completion.
=brishz_copy=y= (or =brishz_c=y=) copies a replay command through =pbcopy=,
with binary stdin embedded and credentials read from their normal sources.

Check the zsh wrapper separately with
=zsh -f zshlang/tests/brishz-default.zsh= from the scripts root. It uses mock
clients to check argv, stdin, status, session shorthand and the dependency
guard without touching a garden.

* Layout
- =main.go=: the environment, the configuration and the dispatch.
- =async.go=: detached workers, stdin handoff and inherited configuration.
- =copy.go=: clipboard replay with argv, options and binary stdin.
- =command.go= and =quote.go=: the command text, as =brishzq.zsh= builds it.
- =stdin.go=: streamed stdin, with the copy a fallback needs; each request
  reads it through its own reader, which replays what earlier ones read.
- =tempfile.go=: the temp file that carries stdin to the JSON API, removed on
  exit and on signals.
- =signals.go=: SIGHUP, SIGINT and SIGTERM run the cleanups, then end us with
  the same signal; one ignored at start stays ignored.
- =transport.go=: the raw API, the JSON fallback and the replies.
- =stream.go=: the streaming API: the frame reader, its fallbacks, and the
  connection closed on a signal.
- =jqtext.go=: invalid UTF-8 replaced the way jq replaces it, for the JSON
  API's strings.
- =proxy.go=: the proxy from the environment, as curl picks it.
- =curlerr.go=: Go's transport errors as curl's exit codes.

* Test
#+begin_src zsh :eval never
cd "${NIGHTDIR}/golang/brishzgo" && go test ./...
#+end_src

The unit tests need no garden. They check the quoters against zsh itself
(random byte strings, quoted, must come back exactly through
=zsh -f= =print -rn --=, and the text must match zsh's =(qq)= and =typeset -p=),
the U+FFFD replacement against jq itself, the proxy choice against curl
itself, the command assembly, the request
shapes, the temp file's removal on SIGTERM, and the replies, fallback and
transport failures against fake gardens built on =net/http/httptest=.
=binary_test.go= runs =brishz_binary=y= over the raw and streaming APIs
against a fake of each garden generation: binary mode, legacy mode with and
without the =binary=1= option, binary mode without it, no raw API (404 or
405), and no binary fields at all. The
zsh tests are skipped where zsh is missing. Run them with =-race= as well:
=TestFallbackKeepsStdinOrder= has the HTTP transport's goroutine and ours
reading stdin at the same time.

The streaming API's frame reader is checked against a reference decoder
with the reply split at every offset, one byte at a time and cut short at
every offset, and by a fuzz target that splits any body anywhere:
#+begin_src zsh :eval never
go test -run '^$' -fuzz FuzzReadFrames -fuzztime 60s
#+end_src
=TestStreamSignals= builds the binary and checks that SIGINT, SIGTERM and
SIGHUP mid stream close the connection and kill it with the same signal.
=TestAsyncDetached= checks return before the HTTP reply, preserved input,
caller-group signals, silent output and fallbacks. =TestCopyReplay= uses a
mock =pbcopy= and executes the copied script against a fake garden, comparing
the original and replayed requests, including binary stdin and transport
options. These tests do not touch the user's clipboard.

Two more are skipped unless pointed at something:

- the parity test runs =brishzq.zsh= and =brishzgo= on a corpus of argv lists
  and environments against a recording fake garden, and compares the command
  bytes each sent, and their JSON text requests field by field (with
  =MAGIC_READ_STDIN=, also the temp file each one's command reads):
  #+begin_src zsh :eval never
  BRISHZGO_TEST_BRISHZQ="${NIGHTDIR}/zshlang/wrappers/brishz/brishzq.zsh" go test -run Parity
  #+end_src
- the integration tests run the built binary against a real garden, never
  the one Hammerspoon uses: a smoke garden on its own port, with a throwaway
  key. =BRISHZGO_IT_KIND= says what the garden is: =binary= (the raw and
  streaming APIs, binary mode), =legacy= (the same with =BRISH_BINARY=0=),
  =preopt-binary= / =preopt-legacy= (the raw and streaming APIs, but older
  than their =binary=1= option, such as =7de4a42=),
  =nostream-binary= / =nostream-legacy= (the raw API but no streaming API,
  such as =0fd2752=), =old-binary= / =old-legacy= (no raw API, such as
  =42ddc9d=), or =pre-binary= (no binary mode at all, such as =cc390bc=).
  Every kind runs every command; the output is compared exactly where that
  garden can carry it. The integration harness explicitly disables streaming
  for its raw/JSON checks. =BRISHZGO_IT_STREAM=y= runs them all with
  =brishz_stream=y= as well; the =TestITStream= ones set it themselves, and
  one of them sends a real Ctrl-C (SIGINT) mid command and checks that the
  command never finishes:
  #+begin_src zsh :eval never
  BRISHZGO_IT_ENDPOINT=http://127.0.0.1:<port> BRISHZGO_IT_KIND=binary \
      BRISHZGO_IT_HOME=<a HOME whose .keys/brishgarden is that garden's key> \
      go test -run TestIT
  #+end_src
