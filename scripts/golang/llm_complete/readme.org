#+TITLE: llm_complete

Stdlib-only completion for interactive coding agents. The transport and terminal
workers share one binary; input text is always JSON on stdin, never argv.

* Install

The launchers use [agfi:go-local-dep] to install and rebuild this module on
first use. For a manual build, run =go install= in this directory. Go 1.21
or newer suffices; no modules need downloading.

* Dabbrev

=llm_complete dabbrev= reads ={screen, corpora, state}= on stdin and emits
={text, backspaces, state}=. A screen contains =agent= (claude or codex),
=cursor_x= and =cursor_y= (zero-based terminal cells), and =lines= containing
=text= and a =wrapped= boolean. Wrapped says the next physical row continues
this one. The state is returned only after a valid expansion.

Candidates begin with the word or path fragment before the caret. The current
screen is searched by distance, then supplied corpora in order, with stable
deduplication. Repeating completion replaces the previous remainder only when
the complete input and caret still match. Non-ASCII remainders expand once;
they cannot cycle because deletion counts depend on the CLI's grapheme editor.
Claude's NORMAL and VISUAL indicators refuse insertion.

=terminal dabbrev= is the detached kitty worker. The no-UI kitten captures
physical rows and returns immediately. The worker re-reads the prompt before
inserting and stores private cycling state under the XDG state directory.
Failures use kitty's existing error overlay. Only inert, single-line text can
be inserted. State files contain prompt text and are mode 0600 in a 0700 folder.

* Test

#+begin_src sh
 go test ./...
 go vet ./...
#+end_src

All automated fixtures contain fabricated text. Live checks and bindings are
documented in =docs/agent-completion.md= in the shell repository.

Transcript corpus comes from =agent_session completion-context=, cached by
file mtime and size and refreshed after insertion. Other kitty windows are
captured by the kitten; tracked paths come from a time-boxed =git ls-files=.
The current screen stays first. A cold transcript cache costs no insertion
latency; press again after the first worker has warmed it.

* Shared FIM transport

=llm_complete fim= reads one JSON object on stdin with =provider=, =prefix=,
=suffix= and optional =model=, =max_tokens=, =stop= (string or array),
=temperature=, =timeout= (seconds), =strip_space=, =source=, =target= and =log=.
Completion bytes go to stdout, without a final newline unless stdout is a
terminal. Errors are one stderr line beginning =fim-get:=. HTTP and API-key
errors return 1. Network errors retain curl-compatible exit codes (timeout
28, DNS 6, connect 7, certificate 60, other transfer errors 52).

=fim providers= prints names sorted; =fim providers --json= prints entries
with =name=, =model=, =endpoint=, =key_env=, =extract= and provider overrides.
Keys come from those environment variable names, never from stdin or argv.
HTTP(S)_PROXY and NO_PROXY are honored; ALL_PROXY is intentionally ignored.

The optional =~/.config/llm_complete/providers.json= merges provider fields
over the built-in table. =LLM_COMPLETE_CONFIG= can select another file for
tests. Omitted fields inherit. Explicit call fields override provider fields,
then Go defaults apply (64 tokens, newline stop, temperature 0, 20 seconds,
leading-space stripping off). Zero tokens and empty/null stop disable them.

#+begin_src json
{
  "providers": {
    "local": {
      "endpoint": "http://localhost:8000/fim",
      "model": "local-model",
      "key_env": "",
      "extract": "text",
      "max_tokens": 80
    }
  },
  "default_provider": "codestral",
  "agent_fim": {"prefix_chars": 2000, "suffix_chars": 1000, "reply_chars": 1500, "log": true},
  "logging": {"sources": {"zsh": false}, "max_bytes": 1048576, "files": 4}
}
#+end_src

Provider reply shapes are =chat= for choices[0].message.content and =text=
for choices[0].text. No caller maintains its own provider table.

* Agent context and logs

=agent-context= reads ={screen, last_reply, source, target, provider}= and
optional FIM parameters on stdin, returning the assembled FIM request. Context
budgets are Unicode code points: last 2000 prompt prefix, first 1000 suffix,
and last 1500 assistant reply by default. An absent reply falls back to the
screen above the input. =terminal fim= performs this asynchronously through
the generalized launcher and validates prompt, caret, agent process identity
and request generation before insertion.

Agent requests log by default; other sources require opt-in. Logs are readable
text in =~/logs/llm_complete/=, with 0700 directories and 0600 files, at most
1 MiB per file and four files by default. The exact resolved body parameters,
verbatim prefix, =⟦CURSOR⟧=, suffix, timing, outcome and completion are recorded.
No keys or headers are recorded. See =logging= and =agent_fim= in the example.
=LLM_COMPLETE_LOG_DIR= selects scratch storage for tests. A per-call =log=
boolean overrides source settings and the agent default.

=fim --shell= is the zsh adapter: NUL-delimited field/value pairs on stdin.
=fim default-provider= exposes the configured default for shell initialization.
No serializer receives buffer text as an argument.

* Screen boundaries

Kitty wrap-marker output separates physical rows with CR; LF following CR
marks a hard break. The native kitten and remote reread use matching flags.
Full-width editor rows also join when the CLI wraps them without a terminal
continuation flag. A hard newline exactly at that margin is ambiguous, as are
intentional trailing spaces versus terminal padding. Internal blank hard lines
remain in the prompt. The opt-in live harness accepts =--multiline-only=.

Git path queries have a 15 ms keypress deadline. A detached helper also caches
tracked paths, validated against the Git index's modification time and size.
A cold command that exceeds the deadline does not lose the corpus permanently;
the next press uses the warmed cache. A live scratch completion used tracked
paths from an existing repository; tests also cover inherited vcsh environment
removal and invalidation after an index change.
