* Fixes

- Telethon 1.43.2 requires =types.Poll(hash=...)=; new outgoing polls now pass =hash=0= when constructing =InputMediaPoll=.
- Poll command usage now accepts the standard `--` end-of-options separator before receiver/question.
- Python sender now exits before sending when the destination/receiver is empty or whitespace-only.
- Poll command now supports `--allow-adding-options` (`allow_adding_options` in Bot API, `open_answers` in Telethon) so users can suggest new answer options; it is rejected for anonymous and quiz polls.
- Poll options now default to Markdown link parsing; `[label](https://example.com)` becomes visible option text plus link media, and `--option-json` exposes Bot API `InputPollOption` rich media objects.
- Telethon Markdown poll links now use `MessageEntityTextUrl` in option text instead of `PollAnswer.media`, because Telegram rejects webpage media in poll answers with `ANSWER_0_MEDIA_INVALID` for bot sends.
