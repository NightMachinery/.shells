# Disabled: designs we removed on purpose

Write-ups of mechanisms that were built, worked, and were then taken out
again. They live here rather than in the git history because the *reasoning*
usually outlives the code: the next person to want one of these needs to know
why it went, not just that it did.

Each file says what the thing did, why it existed, why it was removed, and —
where it would be wired again — what has to come back with it.

Nothing here is live. If a document in this directory describes something you
can still run, it belongs in `docs/` instead.
