# Icon licence

`icon.png` and `icon-180.png` are the Twemoji tram car (U+1F68B), from
<https://github.com/jdecked/twemoji> (the maintained fork; Twitter archived the
original in 2022).

Graphics licensed under **CC-BY 4.0**: <https://creativecommons.org/licenses/by/4.0/>

`icon-180.png` is the same artwork rescaled and flattened onto a light background. A
rescale is a derivative work, so it carries the same licence and the same attribution.

CC-BY asks for attribution wherever the work is distributed, and this repository is
public, which is why the notice is here rather than only in the page that uses it.

Why a tram car and not a train: the mark has to survive 16 pixels in a browser tab. The
train, light rail and tram emoji are all pale and low contrast, and shrink into a smudge;
the tram car is a red box with a dark outline and is still recognisable. The metro emoji
reads at that size too, being a dark disc, but it names the one mode these boards do not
show.
